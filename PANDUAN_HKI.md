# Menyiapkan Dokumen Pengajuan Hak Cipta Program Komputer

1. **Finalkan aplikasi:** pastikan semua menu bekerja dan kode final tersimpan.
2. **Identitas ciptaan:** judul aplikasi, ringkasan fungsi, versi dan tanggal pertama publikasi (jika ada), identitas pencipta, dan pemegang hak cipta. Tanyakan pengaturan kepemilikan ke pihak kampus bila karya dikembangkan dalam kegiatan kampus.
3. **Dokumentasi/cover PDF:** cover dengan judul dan identitas; tangkapan layar beranda, dataset, evaluasi, confusion matrix, feature importance, prediksi; panduan langkah penggunaan; cuplikan atau listing source code sebagai contoh program.
4. **Rujukan data:** nyatakan dataset sekunder bersumber dari Zanela Lima dkk. (2025). Jangan mengklaim data tersebut dibuat sendiri.
5. **Pengajuan:** lakukan pencatatan melalui https://hakcipta.dgip.go.id/ mengikuti persyaratan dan formulir terkini.

Menurut laman syarat dan prosedur DJKI, contoh ciptaan **Program Komputer** berupa **cover, program, dan manual penggunaan program** dalam **PDF** (hingga 20 MB). Periksa kembali persyaratan administratif, surat pernyataan, dan bukti hak ketika akan mendaftar.

Sumber: https://www.dgip.go.id/menu-utama/hak-cipta/syarat-prosedur
